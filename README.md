# 图表对齐判断

判断一张已经画好的图，是否和三句话对齐：要回答什么、给谁看、看完该做什么。

结论按背景、受众、洞察给出。画面需要改时，只指出一处。

## 安装

把 `.cursor/skills/chart-alignment` 复制到：

- 只在当前项目使用：`<项目>/.cursor/skills/chart-alignment`
- 在所有项目使用：`~/.cursor/skills/chart-alignment`

## 使用

发来一张图，并写上这三句：

1. 要回答什么
2. 给谁看
3. 看完该做什么

三句可以写在同一段话里。缺了图，或缺了其中一句，会先停下追问，不会开始判断。
